# カズタマ鑑定書

カズタマ数霊学にもとづいた、数理・姓名・波動の分析アプリです。

## このアプリでできること

- 生年月日から **数理盤**（年盤・月盤・日盤）を生成
- **姓名判断**（画数・単数化・破壊数との照合）
- **波動テーブル**（体内時計・90年分）の表示
- **鑑定データの生成**（NotebookLM連携用）

---

## 鑑定書を作成するには

このアプリは**分析データを生成するツール**です。
鑑定書を作成するには、別途 **鑑定資料** と **NotebookLM** が必要です。

### 手順

**1. アプリで鑑定データを生成**
- 生年月日・姓名を入力して「表示」
- 「📋 鑑定データを生成」ボタンでデータをコピー

**2. NotebookLMに鑑定資料をアップロード**
- https://notebooklm.google.com にアクセス
- 鑑定資料をアップロード（下記参照）

**3. 鑑定データを貼り付けて鑑定書を生成**
- NotebookLMのチャット欄にデータを貼り付け
- 鑑定書が自動生成されます
